# RAGBase

Personal knowledge base on DigitalOcean. Ingests documents, emails, images, and videos from Dropbox. Exposes an MCP server so Claude Desktop can search and answer questions across your entire corpus with citations.

## Architecture

```
Dropbox Sync Folder
        │
        ▼ (every 5 minutes, cron via APScheduler)
┌─────────────────────────────────────────┐
│           Ingestion Pipeline            │
│  PDF → PyMuPDF                          │
│  Word → python-docx                     │
│  Email → extract-msg / stdlib email     │
│  Image → Tesseract OCR                  │
│  Video → Whisper (medium)               │
│  All → chunk → BGE-small embed → SQLite │
└─────────────────────────────────────────┘
        │
        ▼
SQLite + sqlite-vec (local, encrypted backups)
        │
   ┌────┴────┐
   ▼         ▼
FastAPI     MCP Server
Dashboard   (Claude Desktop)
Port 8000   Port 8001
        │
        ▼
   Caddy (HTTPS, auto-cert)
   Port 443
```

## Stack

| Component | Choice | Why |
|---|---|---|
| Vector DB | SQLite + sqlite-vec | Zero deps, one file, HNSW ANN search |
| Embeddings | BGE-small-en-v1.5 | Best speed/quality on CPU |
| PDF | PyMuPDF | Fastest, best layout handling |
| OCR | Tesseract | Offline, no API cost |
| Video | Whisper medium | Offline, best accuracy/speed balance |
| Proxy | Caddy | Auto HTTPS, zero config |
| Auth | Bearer token | Simple, sufficient for personal use |
| Backup encryption | Fernet (AES-128-CBC) | Standard library, reliable |

## Embedding Model Tradeoffs

| Model | Dims | Quality | Speed (CPU) | RAM |
|---|---|---|---|---|
| **bge-small-en-v1.5** | 384 | ★★★★☆ | ~800 ch/s | 90MB |
| bge-base-en-v1.5 | 768 | ★★★★★ | ~300 ch/s | 440MB |
| nomic-embed-text | 768 | ★★★★☆ | ~280 ch/s | 570MB |
| all-MiniLM-L6-v2 | 384 | ★★★☆☆ | ~1200 ch/s | 80MB |

BGE-small is the default. To swap: change `embedding.model_name` in `config/general_settings.json` and run `python scripts/reindex.py`.

## Installation

```bash
# On your DigitalOcean droplet (Ubuntu 22.04)
git clone https://justtokins/Personal_RAG_SYSTEM /tmp/ragbase
cd /tmp/ragbase
sudo bash scripts/setup.sh
```

The setup script:
- Installs system dependencies (Python 3.11, Tesseract, ffmpeg, Caddy)
- Creates a `ragbase` system user with restricted permissions
- Sets up a Python virtualenv and installs all dependencies
- Downloads Whisper medium model (~1.5GB)
- Configures firewall (ports 22 and 443 only)
- Installs and enables systemd services
- Initialises the SQLite database
- **Auto-generates** `MCP_BEARER_TOKEN` and `ENCRYPTION_KEY` — no manual action needed

## Configuration

Edit `/opt/ragbase/.env` after running setup:

```env
# Auto-generated by setup.sh — do not change:
MCP_BEARER_TOKEN=<auto-generated>
ENCRYPTION_KEY=<auto-generated>

# Required — fill these in:
DOMAIN=ragbase.yourdomain.com
DROPBOX_APP_KEY=...
DROPBOX_APP_SECRET=...
DROPBOX_REFRESH_TOKEN=...   # run: python scripts/dropbox_auth.py (on your laptop)

# Optional — tagging is skipped if missing:
ANTHROPIC_API_KEY=sk-ant-...
```

> **Dropbox setup:** Run `python scripts/dropbox_auth.py` on your **laptop** (not the server) to generate the three `DROPBOX_*` credentials via the OAuth flow. See `scripts/dropbox_auth.py` for step-by-step instructions.

Edit `config/general_settings.json` for:
- Whisper model size (`medium` → `large` for better accuracy)
- Chunk size and overlap
- Backup schedule
- Search result count

Edit `config/tags.json` to customise the auto-tagging taxonomy.

## Claude Desktop Config

Add to `~/.claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "ragbase": {
      "url": "https://YOUR_DOMAIN/mcp/sse",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_BEARER_TOKEN"
      }
    }
  }
}
```

Replace `YOUR_DOMAIN` and `YOUR_MCP_BEARER_TOKEN` with the values from `/opt/ragbase/.env`.

## MCP Tools Available to Claude

| Tool | Description |
|---|---|
| `search_knowledge` | Semantic search across corpus |
| `get_document` | Full document text + metadata |
| `list_recent` | Recent additions with filters |
| `get_video_segment` | Transcript at a specific timestamp |

## CLI Commands

```bash
# Manual scan (also runs automatically every 5 minutes)
curl -X POST https://YOUR_DOMAIN/api/scan \
     -H "Authorization: Bearer YOUR_TOKEN"

# Manual backup
curl -X POST https://YOUR_DOMAIN/api/backup \
     -H "Authorization: Bearer YOUR_TOKEN"

# Reindex after swapping embedding model
python scripts/reindex.py

# Restore from backup
python scripts/restore_backup.py \
    --backup /opt/ragbase/backups/ragbase_2024-01-15_02-00.db.enc
```

## Performance

| Task | Target | Notes |
|---|---|---|
| 20-page PDF ingest | < 60s | Parallel split + batch embed |
| 1-hour video transcribe | < 20min | Whisper medium, CPU |
| Semantic search | < 2s | sqlite-vec HNSW at 1M chunks |
| 10k docs / 1M chunks | ✓ | sqlite-vec tested at this scale |

## Security

- Firewall: ports 22 (SSH) and 443 (HTTPS) only
- SSH key-only authentication (configure separately)
- Bearer token required for all API and MCP calls
- Backup files encrypted with Fernet (AES-128-CBC) before upload
- No telemetry, analytics, or third-party reporting
- Outbound connections: Anthropic API (tagging only), Dropbox (backup upload only), all embeddings run locally
- All credentials in `.env` with `chmod 600` permissions
